# Sales_Dashboard
This project is an interactive Power BI Sales Dashboard designed to analyze sales performance and provide actionable business insights. The dashboard helps stakeholders track key metrics, identify trends, and make data-driven decisions.

"Objectives"
1) Track key sales KPIs
2) Analyze sales trends over time
3) Identify top products and regions

"Key Features"
1) KPI cards for quick performance tracking
2) Sales analysis by product and region
3) Interactive filters and slicers
4) Clean and intuitive dashboard design

"Tools Used"
1) Power BI
2) Excel / CSV
3) Power Query (Data Cleaning)

"KPIs"
1) Total Sales
2) Revenue
3) Quantity Sold
4) Top Products
5) Regional Performance
